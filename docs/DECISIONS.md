- 2026-11-04 · object-storage · Local development uses SeaweedFS 4.52 (`chrislusf/seaweedfs:4.52`, S3 gateway) instead of MinIO. Reason: on 2026-11-04 neither `minio/minio` (Docker Hub: repository does not exist) nor `quay.io/minio/minio` (401 Unauthorized) could be pulled. Alternatives considered: RustFS (Apache-2.0, MinIO-like, but only reached 1.0 recently), Garage (AGPL-3.0, needs a cluster-layout setup step before first use), Zenko CloudServer (no image updates since 2023). SeaweedFS is Apache-2.0, actively maintained, and runs as a single container with `weed server -s3`. Application code must use only the standard S3 API (an S3 client with the endpoint URL from config) so the server can be swapped. Production will use a managed S3-compatible service, chosen later and recorded here.
